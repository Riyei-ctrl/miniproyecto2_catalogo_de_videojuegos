# Catálogo Consultable de Videojuegos - Steam 🎮

**TecNM / Instituto Tecnológico de Orizaba**  
**Ingeniería en Ciencia de Datos** | Estructuras de Datos - Miniproyecto 2

Este proyecto implementa un motor de búsqueda y catálogo de videojuegos utilizando estructuras de datos construidas desde cero en Python: Árbol Binario de Búsqueda (ABB), Árbol AVL y Montículo Binario (Min-Heap sobre arreglo). Cumple con las instrucciones de ejecución reproducibles requeridas para la entrega.

## Requisitos Previos

* **Python 3.10** o superior.
* Entorno de desarrollo (recomendado: Visual Studio Code).
* No se requieren bibliotecas externas de terceros. El proyecto utiliza exclusivamente módulos nativos (`csv`, `sys`, `time`, `math`, `heapq`, `random`, `os`).
